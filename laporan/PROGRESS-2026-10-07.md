## Yang Sudah Selesai

### 1. Time Budget & Timeout
- Time budget 45 detik (`AI_TIME_BUDGET_MS`) mencegah Vercel timeout 60 detik.
- Timeout 20 detik per request (`AI_REQUEST_TIMEOUT_MS`) mencegah request menggantung.
- Cek time budget sebelum retry & sebelum fallback.
- File: `api/lib/providers/gemini.js`, `api/lib/providers/groq.js`.

### 2. Retry & Fallback
- Retry exponential backoff: 1s -> 2s -> 4s, maksimal 3 retry per model.
- Hanya retry untuk 5xx dan 429 (bukan 400/403).
- Patch SDK Gemini: 503 dilempar sebagai `fetch failed` (bug SDK 0.24.1). Sekarang dideteksi sebagai retryable.
- Fallback model: `gemini-3.8-flash` -> `gemini-3.6-flash`.

### 3. Provider Groq (BARU)
- File baru: `api/lib/providers/groq.js`.
- Model default: `openai/gpt-oss-120b` (llama-3.3-70b-versatile sudah deprecated).
- Timeout per request: 20 detik via SDK native.
- Kualitas output: bagus untuk artikel bahasa Indonesia.

### 4. Cascade Multi-Provider
- `api/lib/ai-provider.js` sekarang iterasi urutan provider dari `AI_PROVIDER_ORDER=gemini,groq`.
- Kalau Gemini gagal total -> otomatis coba Groq.
- Kalau Groq juga gagal -> kirim error ringkasan ke frontend.

### 5. Update `generate-blog.js`
- Tidak lagi wajib `GEMINI_API_KEY` saja.
- Cek `hasAnyProviderConfigured()` — minimal satu provider punya API key.

### 6. Fix Preview Panel
- Bug: `tags.toArray is not a function` di `public/admin/product-preview.js`.
- Penyebab: tags dari widget AI berbentuk array biasa, bukan Immutable List.
- Fix: defensive check untuk multi-tipe tags.

### 7. Fix Routing `vercel dev`
- Masalah: `vercel dev` pakai Astro dev, tidak serve `/admin/` dan `/api/`.
- Fix: `vercel.json` pakai `devCommand: "npx serve dist -l $PORT"`.
- Alur lokal: `npm run build` -> `npx vercel dev --listen 3000`.
- File: `vercel.json`, `astro.config.mjs`.

### 8. Environment Variables
- Lokal (`.env`, `.env.local`): lengkap.
- Vercel Production: lengkap.

### 9. Test di Production
- BERHASIL generate artikel via Groq (karena Gemini quota habis).
- Cascade Gemini -> Groq terbukti jalan di production.

## Update: Pin Generator (SELESAI)

### Fitur Baru
- Halaman `/admin/pin-generator.html` — UI generate Pinterest Pin
- Endpoint `POST /api/generate-pin` — render PNG 1000×1500 px
- 3 template style: **minimalis**, **bold**, **editorial**
- Multi-style preview: generate 3 style sekaligus (sequential), user pilih yang cocok
- Tombol download PNG per style

### Tech Stack
- **`satori@0.10.13`** — JSX/HTML → SVG
- **`@resvg/resvg-js@2.6.2`** — SVG → PNG (native, tanpa WASM)
- **Font Inter** (woff) di `api/lib/fonts/`
- **`@vercel/og` diganti** karena tidak support WASM import di Node.js 20

### Alur
1. User buka Pin Generator dari sidebar shortcut
2. Isi form: judul, kategori, URL gambar (atau upload file)
3. Klik "Generate Semua Style"
4. Backend render 3 PNG sequential (~4 detik per style)
5. Preview muncul satu per satu di UI
6. User download style favorit

### Fitur Template
- **minimalis**: Cream, foto rounded shadow, judul bold, CTA bawah
- **bold**: Color block terracotta + charcoal, judul di footer
- **editorial**: Magazine style, header brand, judul besar, divider

### File Baru
- `api/generate-pin.js` (endpoint)

- `api/lib/pin-templates/minimalis.js`
- `api/lib/pin-templates/bold.js`
- `api/lib/pin-templates/editorial.js`
- `api/lib/fonts/Inter-Regular.ttf` (woff format)

### Package Baru
